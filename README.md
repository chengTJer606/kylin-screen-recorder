# 录屏工具（kylin-screen-recorder）

麒麟 UKUI 桌面下的轻量录屏工具：全屏/区域录制、系统声音/麦克风/混音、暂停/继续分段合并、时间戳自动命名、收尾重命名与播放。

> [!WARNING]
> **设备适配声明（自用工具）**：本项目仅针对作者自己的一台电脑开发与实测，**不保证**在其他机型或系统上可用：
>
> | 项目 | 环境 |
> |------|------|
> | 机型 | 华为擎云 L410（麒麟 990 芯片，aarch64 / ARM64） |
> | 系统 | 银河麒麟桌面操作系统 V10 SP1 |
> | 桌面 | UKUI（Wayland 会话） |
> | 依赖 | 系统自带 ffmpeg 4.2.2（需含 kmsgrab）、PulseAudio/PipeWire、python3 + tkinter |
>
> 其他 Linux 发行版 / x86 机器 / GNOME / KDE 环境未经适配，请自行评估。

## 功能

- 全屏录制 + 拖框区域录制（窗口悬停智能识别）
- 声音四模式：无声 / 电脑声音 / 麦克风 / 电脑+麦克风 混音
- 暂停 / 继续（分段法），停止后自动合并为单个 MP4
- 画质三档（流畅 / 高清 / 原画），磁盘空间不足自动安全停止
- 3 秒倒计时（录像内可见完整 3-2-1）、录后重命名 / 另存 / 播放

## 技术原理

- **视频**：`sudo ffmpeg -f kmsgrab` 直接从内核 DRM 层抓屏 —— 绕开 Wayland 下 xdg-desktop-portal 无 UKUI 后端导致的"整屏无法采集"问题
- **音频**：用户态 `ffmpeg -f pulse` 录制 PulseAudio 源（系统声用 sink 的 `.monitor`）
- **暂停**：暂停 = 结束当前段，继续 = 新起一段，停止 = concat 合并 + 音画超前量（F2）校准

## 使用

双击桌面「录屏工具」图标，或运行 `录屏工具.sh`。详见 [使用说明.txt](使用说明.txt)。
